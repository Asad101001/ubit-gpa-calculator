## 3. Web Application Access

Students and faculty can view and download all authentic marksheets directly from the live web application:
1. **Official Marksheets Archive Modal**: Click **"View Official Marksheets (PDF Archive)"** in the Results Portal header or Footer to search, filter by semester, and view any document.
2. **Subject-Filtered Instant Link**: When filtering the Results Portal by any announced course (e.g. `CS-451`), an instant action pill directly opens the official university marksheet PDF in a new tab.
3. **Static File Serving**: All documents are hosted under `/results/{Semester}/{Filename}` for direct linking and download.
